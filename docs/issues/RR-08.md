# RR-08: Add contact notes and safe CSV exports

Status: open local draft; not a published GitHub issue.

Milestone: 4

Planned owner: @joewahy (B, your friend); reviewer: @lakerss6 (A). Recorded locally; not assigned on GitHub.

## Goal

Record useful notes and export only selected, visible demo contact information.

## Dependencies

RR-06; coordinate opportunity references with RR-07

## Starting points

List export utility and contact note UI

## Acceptance criteria

- [ ] Edit notes and tags using the existing persistence boundary.
- [ ] Export the selected list with clear demo provenance and revealed fields only.
- [ ] Quote commas, newlines, and double quotes correctly.
- [ ] Neutralize spreadsheet formula inputs such as =, +, -, and @ prefixes, including leading whitespace/control characters.
- [ ] Never expose an unrevealed email in the export.

## Learning objective

Serialization, untrusted input, and data entitlement boundaries.

## Debugging exercise

Export a note containing a comma, newline, quote, and formula prefix; inspect raw CSV.

## Verification and handoff

Run `npm run typecheck` and `npm run build`. Record relevant manual steps and any focused tests. Have the reviewer reproduce one edge case. Explain one implementation decision in your own words.

## Out of scope

CSV imports, live data exports, or CRM integration.
