Status: open local draft; not a published GitHub issue.

Milestone: 1

Planned owner: @joewahy (B, your friend); reviewer: @lakerss6 (A). Recorded locally; not assigned on GitHub.

## Goal

Add realistic variation to the invented directory while keeping public summaries free of contact details.

## Dependencies

Starter only; coordinate types with RR-01

## Starting points

src/features/contacts/demo-people.ts; src/features/contacts/types.ts

## Acceptance criteria

- [ ] Add at least six synthetic profiles across roles, companies, and locations.
- [ ] Keep unique IDs and isDemo: true on every record; include no real people or email addresses.
- [ ] Explain required fields and role union values; verify all profiles render.

## Guided first steps for beginners

1. Read PersonSummary and describe each field in plain English.
2. Copy one fictional fixture and give it a new ID and invented values.
3. Check the page, then add the remaining profiles one at a time.

Work on one step at a time. Ask for explanations or hints when stuck; the debugging exercise is a learning prompt, not a deliberately planted bug.

## Learning objective

TypeScript unions, readonly data, and separation of fixtures from UI.

## Debugging exercise

Try an unsupported role value locally; explain why it fails typechecking.

## Verification and handoff

Run `npm run typecheck` and `npm run build`. Record relevant manual steps and any focused tests. Have the reviewer reproduce one edge case. Explain one implementation decision in your own words.

## Out of scope

Live datasets or email lookup.
