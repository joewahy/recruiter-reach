## Goal

Draft an introduction for a saved contact and preview exactly what approval will cover.

## Dependencies

Milestone 4; agree immutable snapshot with RR-10

## Starting points

New outreach composer; common message snapshot type

## Acceptance criteria

- [ ] Require sender demo address, revealed recipient, subject, and body.
- [ ] Block unresolved template variables and missing required fields.
- [ ] Keep plain text as text; do not inject HTML.
- [ ] Save drafts and show the final recipient/subject/body together.
- [ ] Editing an approved snapshot invalidates its approval through the shared service.
- [ ] No send action bypasses RR-10.

## Learning objective

Form state, validation, immutable snapshots, and domain/UI separation.

## Debugging exercise

Try unresolved personalization and HTML-like input; verify safe rendering and validation.

## Verification and handoff
